Connect to Adobe

You need Chrome 120 or newer and an authorized Cloud Manager integration. Ask your Adobe administrator for the correct access and product profiles.

  1. Install from the official Chrome Web Store listing. Choose Add to Chrome, then follow the installation steps.
  2. In Adobe Developer Console, open the Cloud Manager project and find its OAuth Server-to-Server credential.
  3. Open the extension’s Settings and enter Client ID, Organization ID, Program ID, Client Secret, and the supplied scopes.
  4. Choose Connect. The extension generates a token and verifies program access.

To use an existing token instead, open Advanced connection controls → Manual access token. Manual tokens need replacing when they expire unless a matching credential is saved for renewal.

Saving a Client Secret is optional and requires consent. The bundled encryption key does not keep saved secrets confidential from someone with access to the profile and extension code. Adobe’s Server-to-Server guidance expects a secure backend; follow your organization’s credential requirements. See the privacy policy and Adobe authentication guidance.

Use the extension

Pipelines

Open an environment to refresh pipeline and execution status. Use group actions for eligible pipelines or individual actions on a pipeline. Current status and the last execution outcome are separate. Production approval controls appear when Adobe exposes a recognized waiting approval step. Confirmations list every affected target; a shared pipeline can affect more than one environment.

Execution history loads only when opened and fetches more pages as you scroll. Refresh updates the catalog and expanded environments. Stop and Reject depend on the actions available from Adobe.

Variables

Choose an environment, search by name or filter by service, then expand a row to edit it. Additions, edits and removals can be saved together. The same variable name can appear in different services. Plain values are prefilled; secret values are write-only.

Drafts survive tab, environment and Refresh changes while the popup remains open. Closing the popup or changing the connection clears them. After Save, the extension tracks the environment update and blocks pipeline starts and approvals until it is ready.

Environments

Set local aliases, move environments up or down, and choose which appear under Pipelines. These preferences are saved in your browser. Opening this tab fetches current environment status.

Appearance

In Settings → Appearance, choose System, Light or Dark. System is the default and follows your computer theme. The preference is saved locally and updates open extension pages without reloading Adobe data.

Common questions

Why can’t I start or approve a pipeline?

The environment may be updating or unavailable, or the pipeline may no longer be eligible. Wait for the update, refresh its status, and check your Cloud Manager permissions. The extension verifies targets and execution state before sending an action.

Why does connecting fail?

Verify that the Client ID and Client Secret belong to the same integration, the organization and program are correct, and the scopes and product profiles allow Cloud Manager access. Use the error from Connect to distinguish invalid credentials, access restrictions, or network failure.

What happens after a request times out?

Read requests can be retried with Refresh. For a timed-out Start, Stop, approval or variable save, inspect the remote state in Cloud Manager before retrying. A timeout does not prove that Adobe rejected the action.

How do I stop automatic token renewal?

In Settings, choose Forget saved secret. Clearing only the token keeps the saved credential, so the next request can generate a new token. Revocation and rotation happen in Adobe Developer Console.

Does the website connect to my Adobe account?

No. The product preview uses fixed sample data. This site has no account connection, analytics, or credential form. Only the installed extension sends authorized requests to Adobe.

Report an issue or ask a privacy question

Open an issue on GitHub ↗. Include the extension version, Chrome version, steps to reproduce, and the error text. GitHub issues are public: remove tokens, secrets, variable values and identifying program details before sharing.

For privacy questions, use the same support channel with a general description only. Do not post credentials or other private account information.
