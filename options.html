Adobe OAuth docs ↗

Generate access token

Credentials are sent only to Adobe over HTTPS to generate tokens and manage Cloud Manager. Tokens remain in memory for this browser session. Privacy policy

Use your Adobe Developer Console OAuth Server-to-Server credential.

Remember credentials

A previous secret is available in temporary session memory. Leave Client Secret empty, consent below, and save to convert it to the new format before restarting Chrome or reloading the extension.

Save your secret to renew access tokens automatically, including after restarting Chrome. No vault password, passkey, or external software is required.

Storage protection: the secret is encrypted with a fixed key bundled with this extension. Anyone with the extension code and your saved data can decrypt it. This is obfuscation, not a secure password vault. Do not use it on an untrusted or shared Chrome profile.

Save secret first to enable automatic renewal. Generate uses an entered secret once, or the saved credential when the field is empty. The secret field clears after credential operations. Tokens renew when an API request needs them; there is no background polling.

Manual access token

Alternatively, paste an existing access token from Adobe Developer Console.

First-time setup

  1. Open your Cloud Manager API integration in Adobe Developer Console and select its OAuth Server-to-Server credential.
  2. Copy the Client ID, Client Secret, and scopes. Enter your Organization ID and Cloud Manager Program ID above.
  3. To enable automatic renewal, review the storage limitation, select the consent checkbox, and click Save secret. Then click Test connection.

No redirect URL or Adobe sign-in window is required. Access depends on the integration's Cloud Manager product profiles.

Tokens stay in Chrome session storage. Missing or expiring tokens renew automatically using your saved secret. Clear token keeps the saved secret; Forget saved secret disables renewal and clears the token. Each user supplies their own authorized Adobe credential; none is included in the extension package.
