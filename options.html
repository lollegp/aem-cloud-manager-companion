Automatic renewal A previous secret is available in temporary session memory. Select the checkbox below and connect to save it before restarting Chrome.

Storage limitation: the secret is encrypted with a fixed key bundled with this extension. Anyone with the extension code and your saved data can decrypt it. This is obfuscation, not a secure password vault. Only save on a trusted, private Chrome profile. Selecting the checkbox confirms you accept this limitation.

Credentials go only to Adobe over HTTPS. Access tokens last for this browser session. Without saving, an entered secret is used once.

Where to find your credentials
  1. Open your Cloud Manager API integration in Adobe Developer Console.
  2. Select the OAuth Server-to-Server credential. Copy its Client ID, Client Secret, Organization ID, and scopes.
  3. Enter the Cloud Manager Program ID, choose whether to save the credential, and select Connect.

Access depends on your integration's Cloud Manager product profiles.
